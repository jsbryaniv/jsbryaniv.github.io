![Halloween Knights](https://shep4.com/blog/2026/11/halloween-costume/assets/final_product.jpg)

The part I want to share here is the sword hilt. Every sword needs a hilt, and I wanted ours to look like the real thing. I have never been good at 3D modeling software, so instead I spent about an hour in Claude Code describing the hilt out loud, and Claude wrote Python code that built the model for me. Then I printed it on my Bambu A1.

Three takeaways if you want to try this yourself:

1. **Code-based CAD is a shortcut to 3D modeling.** CAD (computer-aided design) programs are how people normally draw 3D models, and they take a long time to learn. A code-based CAD library, such as [CadQuery](https://cadquery.readthedocs.io/) for Python, builds the model from code instead. That means you can describe the design to an AI in plain words, like "start with a cylinder for the grip, then add a crossguard that steps out on both sides," and the AI writes the code that builds the model. You still make every design decision; you just skip the part where you draw it by hand.

2. **Every measurement becomes a setting.** In the code, each dimension is a named number at the top of the file: the grip length, the guard width, and the diameter of the hole the blade slides into. When I wanted a wider guard, I asked for it, one number changed, and the model rebuilt itself.

3. **Most of the iteration is making it easy to print.** Getting the hilt to look right was the quick part. Most of my revisions were about printing it well. A 3D printer builds an object one layer at a time from the bottom up, so any part that sticks out over empty air needs temporary "support" material underneath it, which you have to break off after printing. So I kept asking Claude to reshape the hilt so it would need fewer supports. For example, it replaced a flat ledge inside the hilt with a 45-degree slope, because a printer can build a slope that steep without anything underneath it. Telling the AI how the part will be printed shaped the design as much as how I wanted it to look.

![3D Printed Sword Hilt](https://shep4.com/blog/2026/11/halloween-costume/assets/designing_the_hilt.png)

I was genuinely impressed by how well this worked. It opens up a lot of possibilities for future costumes, props, and products!
